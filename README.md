# Week 10 — Model Evaluation and Selection

## Overview

This notebook (`04_model_evaluation_week8.ipynb`) performs the final evaluation and selection stage of the IPL machine learning project.

The purpose of this stage is to evaluate all trained models from Week 7 using the same unseen test dataset, compare their performance using regression metrics, generate visual analysis plots, and select the best-performing model for final deployment.

The evaluation process includes:

- Loading the processed IPL dataset
- Loading all trained machine learning models
- Evaluating regression performance
- Creating performance category confusion matrices
- Checking ROC curve applicability
- Comparing all models
- Selecting the best model based on RMSE
- Saving final evaluation results and the selected model
